### 1.4 Migracja katalogów (logika)

**Dodać w `apps/backend/init.py`:**
```python
def get_data_dir(project_dir):
    ouro_dir = project_dir / ".ouro"
    legacy_dir = project_dir / ".auto-claude"

    if ouro_dir.exists():
        return ouro_dir
    elif legacy_dir.exists():
        # Auto-migrate
        legacy_dir.rename(ouro_dir)
        log.info("Migrated .auto-claude/ → .ouro/")
        return ouro_dir
    else:
        return ouro_dir
```
